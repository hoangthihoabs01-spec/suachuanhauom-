# CÂU LỆNH TẠO WEBSITE KIẾN TẠO ĐỜI MỚI XAI

Skill cộng đồng dành cho học viên muốn chuyển **một ý tưởng, hình ảnh, nội dung hoặc thông tin thương hiệu tùy chọn** thành **một siêu câu lệnh yêu cầu AI tạo website HTML/CSS/JavaScript** hoàn chỉnh.

## Nguồn phát triển
Được biên soạn **trực tiếp từ Skill CÂU LỆNH TẠO WEBSITE phiên bản 1.0**, chuyển thành bản sử dụng chung. **Không sử dụng bản V2** và không thêm bộ kiểm thử/rubric đặc thù của V2.

## Nội dung gói
- `SKILL.md`: Hướng dẫn hành vi, phân luồng nhiệm vụ, quy trình 8 bước, chuẩn đầu ra.
- `references/VI_DU_SU_DUNG.md`: Ví dụ đầu vào ngắn, thông tin tự chọn, cách sử dụng.

## Hướng dẫn sử dụng
1. Cài hoặc tải `SKILL.md` vào môi trường hỗ trợ Skill/hướng dẫn tùy chỉnh.
2. Gửi ý tưởng như: “Tạo câu lệnh HTML cho quán cà phê sân vườn có thực đơn và nút liên hệ.”
3. Có thể gửi kèm ảnh, logo, tài liệu, số điện thoại, Zalo, YouTube, Facebook, tên miền. **Không bắt buộc**.
4. Nhận **một siêu Prompt**; sao chép vào công cụ AI lập trình website (Gemini, ChatGPT, Google Antigravity...).
5. Kiểm tra mã nguồn, quyền sử dụng hình ảnh, chức năng và thông tin trước khi xuất bản lên GitHub Pages.

**Chú ý:** Skill mặc định **viết câu lệnh tạo website**, không tự lập trình hoặc đăng website. Những chức năng cần cơ sở dữ liệu, thanh toán, đăng nhập, AI có API bảo mật... cần dịch vụ bổ sung; không được tuyên bố HTML tĩnh tự thực hiện được.
